nRF Connect SDK – Offline Install Assistant

Generates the scripts for preparing a USB stick on an online machine and installing from it on an offline machine. Runs fully offline; nothing is sent anywhere.

A web page can't install software itself. Run the generated scripts in a terminal. Command flags can differ between nrfutil versions, so check nrfutil <command> --help if one fails.
